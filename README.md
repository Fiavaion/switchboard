# Switchboard

Free, open-source macOS menu-bar utility: Windows-style per-window Cmd+Tab and screenshots straight to the clipboard. No paywall, no telemetry, no network.

Docs: [`docs/RESEARCH.md`](docs/RESEARCH.md) · [`docs/PRD.md`](docs/PRD.md) · [`CLAUDE.md`](CLAUDE.md)

## Build
Requires Xcode Command Line Tools (`xcode-select --install`) and macOS 14+.
```bash
scripts/build.sh && open build/Switchboard.app
```
